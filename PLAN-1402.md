# Plan: Add five gradients as tokens (#1402)

Issue: https://github.com/ithaka/pharos/issues/1402

> Working notes for this branch. Remove this file before opening the pull request.

## Scope

Add five `linear-gradient(100deg, …)` values from the issue as design tokens. Applying them to components (icons, buttons) is follow-up work.

| Token (proposed)                   | Value from issue                                                 |
| ---------------------------------- | ---------------------------------------------------------------- |
| `gradient.subdued.cyan-blue-red`   | `linear-gradient(100deg, #197D97 0%, #194D72 30%, #990000 100%)` |
| `gradient.subdued.cyan-blue`       | Unclear. See open question 2                                     |
| `gradient.subdued.blue-red`        | `linear-gradient(100deg, #194D72 0%, #990000 100%)`              |
| `gradient.saturated.cyan-blue-red` | `linear-gradient(100deg, #27CAE1 0%, #0D3071 40%, #990000 100%)` |
| `gradient.saturated.cyan-blue`     | `linear-gradient(100deg, #27CAE1 0%, #0D3071 100%)`              |

## Findings

- Tokens are Style Dictionary JSON in `packages/pharos/tokens/`. `packages/pharos/scripts/build-tokens.mjs` builds them into SCSS, CSS, CSS-in-JS and TS outputs, following `packages/pharos/style-dictionary.config.js`.
- The saturated stops match existing tokens in `packages/pharos/tokens/color/base.json`: `#27CAE1` = `color.glacier-blue.base`, `#0D3071` = `color.night-blue.base`, `#990000` = `color.jstor-red`. These matches come from converting the HSL values by hand. Not yet verified against build output.
- The subdued stops `#197D97` and `#194D72` have no matching color token.
- `packages/pharos/src/components/progress-bar/pharos-progress-bar.ts:35` builds its gradient at runtime. The stop depends on `value`, and it uses `to right`, not `100deg`. A fixed token can't replace it directly.
- The site already has a gradient display at `packages/pharos-site/src/components/statics/color/ColorGradients.tsx`, and token pages under `packages/pharos-site/src/pages/design-tokens/`.
